# Admin UI

Npflared ships a small web interface for administrators, served by the registry worker at `/_/admin` and protected by [Cloudflare Access](./authentication).

## Packages
- A searchable, paginated table of every published package with its latest version, version count and last update.
- A package page with the description, dist-tags, a copyable install command, the list of published versions and, for the selected version, the rendered readme and the dependencies.

Readmes are rendered from Markdown and sanitised before they are displayed. Package management is read-only.

## Tokens
- The list of registry tokens with their names, scopes and creation dates. Secrets are never displayed.
- A form to create a token with any combination of scopes, using `*` for every package or an explicit list of package names.
- The generated token is shown exactly once, with a copy button.
- Revocation with a confirmation step.

## How it is served
The UI is a Svelte 5 single-page application (`apps/admin`) built with Vite, Tailwind CSS 4 and shadcn-svelte. `pnpm build` writes it to `apps/api/public/_/admin`, which the worker serves as [static assets](https://developers.cloudflare.com/workers/static-assets/) with `run_worker_first`, so that every request to the admin area goes through admin authentication before anything is served. Deep links are answered with the application shell.

`pnpm deploy` in `apps/api` builds the UI before deploying the worker. If the UI has not been built, the admin area answers `404`.

## Developing the UI
1. In `apps/api`, copy `.dev.vars.example` to `.dev.vars` (this selects the `local` admin authentication provider, which only trusts requests addressed to `localhost`), apply the local migrations with `pnpm migrate:local`, then start the worker with `pnpm dev`.
2. In `apps/admin`, start Vite with `pnpm dev` and open `http://localhost:5173/_/admin/`. Requests to `/_/admin/api/*` are proxied to the worker.

Alternatively build the UI (`pnpm build` in `apps/admin`) and open `http://localhost:8787/_/admin/` straight from the worker.
